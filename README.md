# PikaPet

바탕화면에서 포켓몬을 키우는 프로그램입니다. 화면 위를 걸어 다니고, 밥을 주고,
야생 포켓몬과 배틀하고, 도감을 채웁니다.

## 내려받기

**[최신 버전 받기 →](https://github.com/Raspicor/appsol_pokemon/releases/latest)**

macOS용은 `PikaPet-0.0.4.dmg` 같은 이름의 파일입니다. Apple Silicon(M1 이후) 맥에서
동작합니다.

**따로 설치할 것은 없습니다.** 파이썬이든 뭐든 필요 없고, 앱 안에 다 들어 있습니다.
용량이 115 MB인 이유도 그것입니다.

Windows를 쓰신다면 [Windows에서 쓰기](#windows에서-쓰기)로 내려가세요.

## 설치 (macOS)

### 1. DMG를 열고 Applications로 끌어다 놓으세요

받은 `.dmg` 파일을 두 번 누르면 창이 열립니다. 거기 있는 **PikaPet**을
**Applications** 폴더로 끌어다 놓으세요.

### 2. 처음 실행할 때 한 번, 보안 설정을 통과해야 합니다

PikaPet을 두 번 눌러 실행하면 macOS가 **"열 수 없습니다"** 같은 경고로 한 번
막습니다. Apple에 개발자 등록(연 $99)을 하지 않아서 생기는 단계입니다.
프로그램에 문제가 있다는 뜻은 아니고, 한 번만 통과하면 다음부터는 안 나옵니다.

**통과하는 방법:**

1. 그 경고창의 **확인**을 누릅니다.
2. **시스템 설정** → **개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려가면 `"PikaPet"이(가) 차단되었습니다` 라는 줄이 있습니다.
   그 옆의 **그래도 열기**를 누릅니다.
4. 암호를 넣으면 실행됩니다.

터미널이 익숙하시면 이 한 줄로도 됩니다:

```
xattr -dr com.apple.quarantine /Applications/PikaPet.app
```

### 3. 끝

파이리가 화면에 나타나서 돌아다니기 시작합니다.

## 쓰는 방법

### 메뉴 — 펫을 우클릭

포켓몬 위에서 **우클릭**하면 거의 모든 기능이 나옵니다. 밥 주기, 스킬, 훈련, 도감,
진화, 일일 퀘스트(광산 / 뽑기 / 수련 / 미니게임), 메가진화, 크기 조절, 설정, 종료.

### 메뉴 바의 ◓ — 우클릭으로 못 가는 것들

화면 맨 위 메뉴 바에 **◓** 아이콘이 생깁니다. 여기에는 우클릭 메뉴에 **없는**
항목이 들어 있습니다:

| 항목 | 언제 쓰나 |
|---|---|
| 🔴 몬스터볼에서 꺼내기 | 펫이 볼에 들어가면 창이 숨어서 우클릭할 대상이 없어집니다. **이때 여기서 꺼내세요.** |
| 🌿 야생 포켓몬 확인 | 야생 포켓몬이 나타났다는 알림을 놓쳤을 때 |
| ⚔ 배틀 창 복구 | 배틀 창을 최소화했거나 잃어버렸을 때 |
| 🎯 화면 중앙으로 부르기 | 펫이 화면 밖이나 다른 모니터로 걸어가서 안 보일 때 |
| 🔔 알림 테스트 | 알림이 오는지 확인 |

### 옮기기

포켓몬을 **끌어서** 원하는 자리에 놓으면 됩니다. 창도 제목 줄을 끌어서 옮깁니다.

## 이상할 때

### 포켓몬이 안 움직여요

**배틀 창이 열려 있으면 움직이지 않습니다.** 원래 그렇게 만들어져 있습니다.
동료 포켓몬은 그동안에도 계속 돌아다니기 때문에 본체만 멈춘 것처럼 보입니다.
배틀 창을 닫거나 배틀을 끝내면 다시 움직입니다.

배틀 창이 안 보이는데도 멈춰 있다면 최소화된 것일 수 있습니다 —
메뉴 바 **◓ → ⚔ 배틀 창 복구**를 눌러보세요.

**다른 모니터에 가 있는 경우도 있습니다.** 화면이 두 대 이상이면 옆 화면까지
걸어갑니다. 메뉴 바 **◓ → 🎯 화면 중앙으로 부르기**로 끌어오세요.

### 포켓몬이 사라졌어요

- 몬스터볼에 들어간 것 → 메뉴 바 **◓ → 🔴 몬스터볼에서 꺼내기**
- 화면 밖으로 나간 것 → 메뉴 바 **◓ → 🎯 화면 중앙으로 부르기**

### 알림을 눌렀는데 스크립트 편집기가 열려요

알려진 제한입니다. macOS는 개발자 등록이 안 된 프로그램에 알림 권한을 주지 않아서,
PikaPet이 다른 경로로 알림을 띄우고 있습니다. 그래서 배너의 주인이 PikaPet이
아닙니다.

**알림 대신 메뉴 바 ◓ 를 쓰세요.** 야생 포켓몬 확인도 거기 있습니다.

### 새 버전이 나왔는지 어떻게 알아요

PikaPet이 켜질 때 스스로 확인합니다. 새 버전이 있으면 메뉴 바 **◓** 맨 위에
**⬇ 새 버전 받기**가 생기고, 누르면 받는 곳이 열립니다.

업데이트는 새 DMG를 받아서 **1~2번 과정을 다시 하면** 됩니다. 기존 Applications의
PikaPet을 덮어쓰세요. **키우던 포켓몬은 그대로 유지됩니다** — 저장 파일은 앱과
별도로 보관됩니다.

### 저장 파일은 어디 있나요

```
~/Library/Application Support/PikaPet/
```

앱을 지워도 이 폴더는 남습니다. 완전히 지우시려면 이 폴더까지 삭제하세요.
반대로, 다른 맥으로 옮기고 싶으면 이 폴더를 복사하면 됩니다.

## Windows에서 쓰기

Windows에서는 원본 프로그램이 그대로 돌아갑니다. 다만 아직 설치 프로그램이 없어서
저장소를 받아 스크립트를 돌려야 합니다:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
run\pikapet.bat
```

## 만든 것에 대해

이 저장소는 Windows용으로 만들어진 PikaPet을 macOS에서 돌아가게 한 것입니다.
게임 내용은 바꾸지 않았습니다.

빌드와 배포 방법 — 은 **[개발자 노트(DEVELOPER.md)](DEVELOPER.md)** 에 있습니다.

버그를 찾으셨거나 안 되는 것이 있으면
[이슈](https://github.com/Raspicor/appsol_pokemon/issues)로 알려주세요. 그때
**macOS 버전**과 **PikaPet 버전**(Applications에서 PikaPet을 우클릭 → 정보 가져오기)을
함께 적어주시면 찾기가 훨씬 빠릅니다.
