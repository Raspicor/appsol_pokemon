# PikaPet

바탕화면에서 포켓몬을 키우는 프로그램입니다. 화면 위를 걸어 다니고, 밥을 주고,
야생 포켓몬과 배틀하고, 도감을 채웁니다.

## 설치 (macOS)

**필요한 환경: macOS 26 이상, Apple Silicon (M1 이후) Mac.**


### 1. DMG를 열고 Applications로 끌어다 놓으세요

받은 `.dmg` 파일을 두 번 누르면 창이 열립니다. 거기 있는 **PikaPet**을 **Applications** 폴더로 끌어다 놓으세요.

### 2. 처음 실행할 때 한 번, 보안 설정을 통과해야 합니다

PikaPet을 두 번 눌러 실행하면 macOS가 **"열 수 없습니다"** 같은 경고로 한 번 막습니다. 

**통과하는 방법:**

1. 그 경고창의 **확인**을 누릅니다.
2. **시스템 설정** → **개인정보 보호 및 보안**을 엽니다.
3. 아래로 내려가면 `"PikaPet"이(가) 차단되었습니다` 라는 줄이 있습니다. 그 옆의 **그래도 열기**를 누릅니다.
4. 암호를 넣으면 실행됩니다.

**터미널 명령어**

```
xattr -dr com.apple.quarantine /Applications/PikaPet.app
```

## 쓰는 방법

### 메뉴 — 펫을 우클릭

포켓몬 위에서 **우클릭**하면 거의 모든 기능이 나옵니다. 밥 주기, 스킬, 훈련, 도감,
진화, 일일 퀘스트(광산 / 뽑기 / 수련 / 미니게임), 메가진화, 크기 조절, 설정, 종료.

### 메뉴 바의 ◓ — 우클릭으로 못 가는 것들

화면 맨 위 메뉴 바에 **◓** 아이콘이 생깁니다. 여기에는 우클릭 메뉴에 **없는** 항목이 들어 있습니다
| 항목 | 언제 쓰나 |
|---|---|
| 🔴 몬스터볼에서 꺼내기 | 펫이 볼에 들어가면 창이 숨어서 우클릭할 대상이 없어집니다. **이때 여기서 꺼내세요.** |
| 🌿 야생 포켓몬 확인 | 야생 포켓몬이 나타났다는 알림을 놓쳤을 때 |
| ⚔️ 배틀 창 복구 | 배틀 창을 최소화했거나 잃어버렸을 때 |
| 🎯 화면 중앙으로 부르기 | 펫이 화면 밖이나 다른 모니터로 걸어가서 안 보일 때 |
| 🔄 새 버전 확인 | 새 버전이 나왔는지 그 자리에서 확인 |

## 이상할 때

### 포켓몬이 안 움직여요

**배틀 창이 열려 있으면 움직이지 않습니다.** 원래 그렇게 만들어져 있습니다.
동료 포켓몬은 그동안에도 계속 돌아다니기 때문에 본체만 멈춘 것처럼 보입니다.
배틀 창을 닫거나 배틀을 끝내면 다시 움직입니다.

배틀 창이 안 보이는데도 멈춰 있다면 최소화된 것일 수 있습니다 —
메뉴 바 **◓ → ⚔️ 배틀 창 복구**를 눌러보세요.

**다른 모니터에 가 있는 경우도 있습니다.** 화면이 두 대 이상이면 옆 화면까지
걸어갑니다. 메뉴 바 **◓ → 🎯 화면 중앙으로 부르기**로 끌어오세요.

### 포켓몬이 사라졌어요
- 몬스터볼에 들어간 것 → 메뉴 바 **◓ → 🔴 몬스터볼에서 꺼내기**
- 화면 밖으로 나간 것 → 메뉴 바 **◓ → 🎯 화면 중앙으로 부르기**

### 포켓몬 그림이 안 보여요

선택 창에 **(이미지 없음)** 이라고 뜨거나, 포켓몬을 골랐는데 화면에 아무것도
안 나오면 **그림 파일이 앱에 딸려오지 못한 것**입니다. 창과 메뉴는 정상이라
앱이 고장 난 것처럼 보이지 않는 게 특징입니다.

DMG를 다시 열어 **PikaPet을 Applications로 다시 끌어다 놓아주세요** (덮어쓰기).
그래도 같으면 이슈로 알려주시고, 아래 `startup.log`를 함께 올려주세요.

### 알림을 눌렀는데 스크립트 편집기가 열려요
개발자 등록이 안 된 프로그램에 알림 권한을 주지 않아서, PikaPet이 다른 경로로 알림을 띄우고 있습니다.
그래서 배너의 주인이 PikaPet이 아닙니다.
**알림 대신 메뉴 바 ◓ 를 쓰세요.** 야생 포켓몬 확인도 거기 있습니다.

### 새 버전이 나왔는지 어떻게 알아요

두 가지 방법이 있습니다.

**직접 확인:** 메뉴 바 **◓ → 🔄 새 버전 확인**을 누르세요.
**자동 확인:** PikaPet이 켜질 때 스스로도 확인합니다. 새 버전이 있으면 메뉴 바 **◓** 맨 위에 **⬇ 새 버전 설치**가 생깁니다. 
다만 이건 **켤 때 한 번만** 하므로, PikaPet을 며칠 계속 켜 두셨다면 위의 직접 확인을 쓰세요.

### 업데이트는 PikaPet이 알아서 합니다

새 버전이 있으면 설치할지 물어봅니다. 
**설치**를 누르면 내려받아서 스스로 교체하고 다시 열립니다. 
DMG를 받아 다시 끌어다 놓을 필요가 없고, **처음 설치할 때 거쳤던 보안 단계도 다시 나오지 않습니다.**

**키우던 포켓몬은 그대로 유지됩니다** — 저장 파일은 앱과 별도로 보관됩니다.

### 완전 삭제
```
~/Library/Application Support/PikaPet/
```

앱을 지워도 데이터 파일은 남습니다. 완전히 지우시려면 이 폴더까지 삭제하세요.

## Windows에서 쓰기

Windows에서는 원본 프로그램이 그대로 돌아갑니다. 다만 아직 설치 프로그램이 없어서
저장소를 받아 스크립트를 돌려야 합니다:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
run\pikapet.bat
```
